# 계획: 기능·UI·UX 개선

> **상태: 0~4단계 모두 구현 완료 (2026-11-03).** 아래 체크는 기록용이다. 새 개선은 이 문서 끝에 '5단계'로 이어 쓴다.

> 2026-11-03에 실제 화면(폴드 펼침 884×1028, 폴드 접힘·폰 412×915, 아이패드 1180×820, 라이트·다크)을 돌려 보고, 코드를 검토해서 정리한 목록이다.
> AI 코딩 도구는 `AGENTS.md`를 먼저 읽고, **한 번에 한 묶음(또는 한 항목)씩** 구현한다.
> 끝낸 항목은 체크하고 `AGENTS.md`를 갱신한다. 각 항목의 크기: S(반나절 이하) / M(하루 안팎) / L(여러 날).

## 우선순위 한눈에

| 단계 | 묶음 | 왜 먼저 |
|---|---|---|
| **0** | 버그·작은 불편 | 지금 쓰면서 바로 걸리는 것 |
| **1** | 화면 구조·조작감 | 매일 쓰는 동선이 편해짐 |
| **2** | 기록·찾기 기능 | 메모가 쌓일수록 가치가 커짐 |
| **3** | 손글씨 강화 | 펜으로 쓰는 경험 |
| **4** | 데이터 안정성·속도 | 메모가 많아지고 기기를 여럿 쓸 때 대비 |
| 별도 | AI 다듬기 | `docs/PLAN-ocr-refine.md` |

## 0단계: 버그·작은 불편 (바로 고칠 것)

- [x] **0-1 Esc 키가 메뉴만 닫게 (S)**: 설정 메뉴·아래 시트가 열린 상태에서 Esc를 누르면 하루 화면까지 나가 버린다. 열린 메뉴·시트가 있으면 그것만 닫고, 없을 때만 달력으로 돌아가게 한다. (`bind()`의 keydown 처리)
- [x] **0-2 타자 탭 삭제 확인 (S)**: 글이 있는 타자 탭은 확인 없이 지워진다(`deletePage`가 `strokes`만 확인함). 글이 있어도 확인하게 하고, 지운 뒤 5초간 **[되돌리기]** 토스트를 띄운다.
- [x] **0-3 휴대폰 상단 바 넘침 (S)**: 412px 폭에서 달력 제목이 "2026년 1…"로 잘리고 [할 일] 버튼이 화면 밖으로 나간다. 좁은 화면은 제목을 "11월"로 줄이고, 보기 전환은 1-1의 아래 탭으로 옮긴다.
- [x] **0-4 아이콘 깨짐 (S)**: `⌨`가 일부 기기 글꼴에서 작은 네모(■)로 보인다. 탭·버튼 아이콘을 **인라인 SVG**로 통일한다(키보드, 펜, 할 일, 설정, 화살표).
- [x] **0-5 손 닿는 크기 (S)**: 터치 기기에서 버튼·체크칸을 최소 40px로 키운다. 지금 작은 것: 할 일 체크칸 19px, "완료한 것도 보기" 13px, 폰 보기 전환 28px 높이.
- [x] **0-6 손글씨 화면 순서 (S)**: 지금은 펜 도구 줄 → 탭 줄 순서다. **탭 줄 → 펜 도구 줄**로 바꾸고, 펜 도구 줄을 필기장 바로 위에 붙인다.

## 1단계: 화면 구조·조작감

- [x] **1-1 휴대폰 아래 탭 바 (M)**: 600px 미만에서는 [월 | 주 | 메모 | 할 일]을 화면 **아래 고정 탭 바**로 둔다. 엄지로 닿기 쉽고 상단이 넓어진다.
- [x] **1-2 빠른 작성 버튼 (S)**: 달력·모아보기 화면 오른쪽 아래에 **＋ 버튼**을 둔다. 누르면 "오늘 메모"가 바로 열려 키보드 입력이 시작된다. 길게 누르면 [메모 / 할 일 / 손글씨]를 고른다.
- [x] **1-3 상단 바 정리 (S)**: "구글 연결 설정 / 로그아웃" 버튼을 ⚙ 안 "계정" 칸으로 옮긴다. 동기화 상태는 ⚙ 아이콘 옆 작은 점(초록=저장됨, 주황=저장 중, 빨강=오류)으로 보여준다. 지금 휴대폰에서는 상태가 아예 숨겨져 있다.
- [x] **1-4 설정 재구성 (M)**: ⚙을 칸으로 나눈다.
  - 계정·동기화: 로그인, 마지막 동기화 시각, 지금 동기화
  - 화면: 글자 크기, 화면 모드, 음력 표시(2-5)
  - 연동: 구글 Tasks, 네이버 캘린더 상태, AI 변환 상태
  - 데이터: 내보내기(2-4), 저장 공간
- [x] **1-5 "일정·요약" 시트 역할 재정의 (S)**: 왼쪽 패널을 기본으로 숨긴 뒤 이 버튼의 쓸모가 줄었다. 그날 **일정 목록 + 메모 일정 추가**만 남기고, 버튼 이름을 "일정 N"으로 바꾼다. 일정이 0개면 버튼을 숨긴다.
- [x] **1-6 메모 칸 아래 할 일 목록 정리 (S)**: 메모 본문의 ☐ 줄과 아래 체크 목록이 같은 내용을 두 번 보여준다. 체크 목록은 접힌 한 줄("할 일 2 · 남음 1 ▸")로 두고 눌러서 펼친다.
- [x] **1-7 길게 눌러 빠른 동작 (M)**: 달력 날짜를 길게 누르면 [할 일 추가 / 메모 일정 추가 / 손글씨로 열기] 메뉴가 나온다.
- [x] **1-8 처음 쓰는 사람 안내 (S)**: 처음 열 때 3장짜리 짧은 안내를 보여준다(달력→날짜 누르기 / 타자·필기 전환 / 할 일 ☐). ⚙에서 다시 볼 수 있게 한다.
- [x] **1-9 접근성 (S)**: 탭에 `role="tab"`·`aria-selected`, 보이는 키보드 포커스 테두리, 다크 모드 회색 글자 대비(4.5:1 이상)를 점검한다.

## 2단계: 기록·찾기 기능

- [x] **2-1 전체 검색 (M)**: 상단 🔍. 메모·변환된 손글씨·할 일·일정 제목을 한 번에 찾고, 결과를 눌러 그 날짜로 간다. 찾은 단어는 강조한다.
- [x] **2-2 할 일에 기한 자동 인식 (M)**: `☐ 금요일까지 보고서`, `☐ 내일 회의실 예약`, `☐ 11/7 견적서` 같은 표현에서 날짜를 읽어 할 일 모아보기를 기한순으로 정렬한다. 구글 Tasks 마감일도 그 날짜로 맞춘다. 원문 글은 바꾸지 않는다.
- [x] **2-3 메모 서식(템플릿) (S)**: 타자 탭 [서식] 버튼으로 "회의록(일시·참석자·안건·결정·☐ 할 일)", "하루 정리" 등을 넣는다. 서식은 ⚙에서 고친다.
- [x] **2-4 내보내기 (M)**: 하루·한 주·한 달 메모를 **마크다운** 또는 **PDF**로 저장하거나 공유한다(손글씨는 그림으로). 회의록을 메일·메신저로 보내기 쉬워진다.
- [x] **2-5 음력·공휴일 (M)**: 네이버 캘린더처럼 날짜 아래 음력(예: 9.15)을 작게 표시한다(⚙에서 켜고 끔). 네이버를 연결하지 않아도 대한민국 공휴일이 보이게 내장 목록을 둔다.
- [x] **2-6 다른 앱에서 공유받기 (M)**: 안드로이드에서 다른 앱의 글·링크·사진을 "공유 → 필기캘린더"로 오늘 메모에 넣는다(웹 앱 공유 대상, `manifest`의 `share_target`). 아이패드는 지원하지 않는다.
- [x] **2-7 사진·음성 메모 (L)**: 탭 종류에 "사진"(카메라·앨범, 드라이브 저장)과 "음성"(녹음 → 중계 서버 AI로 글자 변환)을 추가한다.
- [x] **2-8 주간 보기 시간표 (M)**: 넓은 화면의 주간 보기에서 시간이 있는 일정을 시간 칸(09시~21시)에 배치한다.

## 3단계: 손글씨 강화

- [x] **3-1 확대·축소 (M)**: 두 손가락으로 필기장을 확대·축소한다. 폰처럼 좁은 화면에서 특히 필요하다. 확대 상태에서도 펜 좌표가 정확해야 한다.
- [x] **3-2 올가미 선택 (L)**: 획을 둘러싸서 선택하고 옮기기·색 바꾸기·지우기를 한다.
- [x] **3-3 종이 배경 (S)**: 줄 / 모눈 / 점 / 무지를 탭마다 고른다.
- [x] **3-4 손글씨 → 글자 즉시 보기 (S)**: 손글씨 탭 위에 변환 결과 한 줄과 [자세히]를 띄운다. 지금은 숨겨진 패널을 열어야만 보인다.
- [x] **3-5 펜 압력 감도 설정 (S)**: ⚙에서 "가볍게 쓰는 편 / 보통 / 세게"를 고른다. 지금은 `inkPoints`의 보정값이 고정이다.

## 4단계: 데이터 안정성·속도

- [x] **4-1 두 기기 동시 수정 합치기 (M)**: 지금은 같은 날짜를 두 기기에서 고치면 나중에 저장한 쪽만 남는다. 드라이브의 `modifiedTime`이 바뀌었으면 **탭 단위로 합친다**(서로 다른 탭은 둘 다 살리고, 같은 탭이면 최신 것 + 충돌 사본 탭).
- [x] **4-2 목록 색인 파일 (M)**: 메모 모아보기·할 일·검색이 지금은 모든 날짜 파일을 하나씩 읽는다. 드라이브에 `index.json`(날짜별 미리보기 글·할 일·수정 시각)을 두고 저장 때마다 갱신해서 처음 여는 기기도 빠르게 만든다.
- [x] **4-3 오프라인 표시 (S)**: 인터넷이 끊기면 상단에 "오프라인 · 기기에 저장 중"을 보여주고, 다시 연결되면 자동으로 올린 뒤 알린다.
- [x] **4-4 휴지통 (M)**: 지운 탭·메모를 30일간 드라이브 `trash/`에 보관하고 ⚙에서 되살린다.
- [x] **4-5 앱 잠금 (선택, M)**: 지문·얼굴 인식(웹 인증)이나 PIN으로 앱을 잠근다. 회사 메모가 있으면 유용하다.

## 다른 AI에게 줄 요청 예시

```
AGENTS.md와 docs/PLAN-improvements.md를 읽고 0단계(0-1 ~ 0-6)만 구현해줘.
- 각 항목을 고친 뒤 tests/smoke.mjs가 통과해야 하고, 고친 항목을 확인하는 시험도 tests/에 추가해줘.
- 앱 파일을 바꾸면 sw.js CACHE와 index.html ?v= 버전을 올려.
- 끝나면 계획서의 해당 항목을 체크하고 AGENTS.md를 최신으로 고쳐서 main에 올려줘.
```
